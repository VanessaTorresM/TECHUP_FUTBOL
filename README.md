## Definición de requerimientos

### Requerimientos funcionales
* RF01: Registro de Torneo
* RF02: Registro de Jugadores
* RF03: Creación y gestión de equipos
* RF04: Búsqueda de Jugadores
* RF05: Inscripción y pagos
* RF06: Configurar Torneo
* RF07: Alineaciones
* RF08: Registro de Partidos
* RF09: Consulta de partidos
* RF10: Tabla de Posiciones
* RF11: Llaves Eliminatorias
* RF12: Estadísticas

### Requerimientos no funcionales
* RNF01: Autenticación con correo institucional y personal
* RNF02: Control de roles y permisos
* RNF03: Registro de acciones (auditoría)
* RNF04: Backend en Spring Boot por capas
* RNF05: Manejo de API REST
* RNF06: Frontend en React con Typescript
* RNF07: Base de datos PostgreSQL
